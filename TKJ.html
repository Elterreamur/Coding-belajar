Materi utama

Panduan dasar teknik komputer dan jaringan.

TKJ bukan hanya tentang menghubungkan komputer, tetapi juga memahami perangkat keras, perangkat lunak, sistem jaringan, dan keamanan data.

CPU, RAM, motherboard, hard disk, dan perangkat input-output menjadi fondasi kerja komputer.

🌐

Jaringan Komputer

LAN, WAN, topologi, IP address, routing, dan switch menjadi bagian penting dalam komunikasi data.

📶

Wireless Network

Wi-Fi, access point, dan konfigurasi jaringan nirkabel membantu perangkat terhubung tanpa kabel.

🛡️

Rangkuman materi

Topik penting yang sering diujikan.

Perangkat keras komputer

  • CPU sebagai pusat pengolahan data.
  • RAM berfungsi menyimpan data sementara.
  • Motherboard menghubungkan semua komponen.
  • Hard disk menyimpan data secara permanen.

Jaringan komputer

  • LAN untuk jaringan lokal.
  • WAN untuk jaringan luas antar daerah.
  • Router menghubungkan jaringan berbeda.
  • Switch menghubungkan perangkat dalam satu LAN.

Alamat IP dan DNS

  • IP address digunakan agar perangkat bisa saling berkomunikasi.
  • DNS menerjemahkan nama domain menjadi IP.
  • Gateway adalah pintu keluar menuju jaringan lain.
  • Subnetting membagi jaringan agar lebih efisien.

Keamanan dan perawatan

  • Firewall membatasi akses tidak sah.
  • Antivirus melindungi dari malware.
  • Backup data mencegah kehilangan informasi penting.
  • Perawatan rutin membuat perangkat lebih awet dan stabil.
